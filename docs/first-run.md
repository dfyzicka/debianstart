# Debian Start

Пошаговая инструкция для первого VPS

## 01 Подключись к серверу

Мастер установит рабочую оболочку, Python, Docker и выбранные панели. В примере ты управляешь сервером из Windows через PowerShell. На macOS и Linux для SSH подойдёт приложение «Терминал».

### Что подготовить

- **Сервер** с чистым Debian 12 или 13. Для m-ui выбери x86-64 или amd64.
- **Данные от хостинга** - IP-адрес, SSH-порт, исходный логин и пароль либо ключ.
- **Архив** `debian-start.zip`. Сохрани его на компьютере, например в «Загрузки».

### НА КОМПЬЮТЕРЕ

Открой PowerShell. В примере адрес сервера - `203.0.113.10`, порт - `22`, исходный логин - `root`. Подставь свои данные от хостинга.

```powershell
ssh -p 22 root@203.0.113.10
```

При первом подключении SSH покажет отпечаток ключа сервера. Сверь его с отпечатком в панели или консоли хостинга и затем подтверди подключение. Если нужен пароль, введи его и нажми Enter. Терминал скрывает символы при вводе.

Если хостинг выдал файл ключа, добавь `-i "путь к файлу"` сразу после `ssh` и `scp`.

> [!TIP]
> Оставь это окно открытым. После входа команды в нём выполняются уже на сервере.

## 02 Загрузи архив и запусти мастер

### НА КОМПЬЮТЕРЕ

Открой **второе** окно PowerShell. Перейди в папку, куда скачал архив, и отправь файл на сервер. Подставь те же адрес, порт и логин.

```powershell
cd "$env:USERPROFILE\Downloads"
scp -P 22 ".\debian-start.zip" root@203.0.113.10:
```

На macOS и Linux перейди в папку с архивом и в команде `scp` используй `./debian-start.zip`. Двоеточие в конце команды отправляет файл в домашнюю папку пользователя на сервере.

### НА СЕРВЕРЕ

Вернись в первое окно. Если подключился как `root`, выполни эти команды по очереди.

```bash
apt-get update
apt-get install -y unzip
unzip debian-start.zip
cd debian-start
bash bootstrap.sh
```

Если вошёл под другой учёткой с правами `sudo`, используй этот вариант.

```bash
sudo apt-get update
sudo apt-get install -y unzip
unzip debian-start.zip
cd debian-start
sudo bash bootstrap.sh
```

> [!NOTE]
> Если у архива или папки другое имя, укажи его в командах. Запускать `bootstrap.sh` нужно из папки, где он лежит.

## 03 Заполни экраны мастера

В меню работают стрелки, Tab и Enter. На экране компонентов **Пробел** включает или выключает пункт.

| Что спросит мастер | Что ввести |
|---|---|
| Имя сервера | Например, `my-vps`. Используй латинские буквы, цифры и дефисы. |
| Логин Linux | Например, `ops`. Это имя для твоих следующих SSH-подключений. |
| Способ входа | Если уже есть ключ, вставь строку из файла `.pub`. Для входа по паролю выбери соответствующий пункт. |
| Пароль Linux | Для новой учётки задай пароль от 12 символов. Он также понадобится для команд с `sudo`. |
| Адрес и порт SSH | Введи адрес и порт из данных хостинга. Мастер вставит их в готовые команды. |

### КАКУЮ ПАНЕЛЬ ВЫБРАТЬ

| Галочка | Для чего |
|---|---|
| **3x-ui** | Веб-панель для Xray. Галочка включена по умолчанию. |
| **m-ui** | Веб-панель для Mieru и Sudoku. Можно включить её одну или вместе с 3x-ui. |
| **dry** | Просмотр контейнеров Docker в терминале. Дополнительная утилита. |

Проверь план и нажми **Установить**. В финальном окне сохрани команду входа, а для каждой панели - её URL, логин и пароль. После этого нажми **Данные сохранены**.

> [!NOTE]
> В режиме «Создать новый Ed25519» мастер попросит парольную фразу для ключа. Команду скачивания `scp` выполни на компьютере через прежнюю SSH-учётку. Удаляй временную копию после проверки нового входа.

## 04 Войди под новой учёткой

### НА КОМПЬЮТЕРЕ

Открой ещё одно окно терминала и выполни команду входа из финального окна мастера. Если выбрал пароль, используй пароль Linux.

### НА СЕРВЕРЕ

После входа проверь права администратора и версию Python.

```bash
sudo -v
python3 --version
```

Если вход прошёл и `sudo -v` выполнилась, можно закрыть исходную SSH-сессию.

### ОТКРОЙ ПАНЕЛЬ В БРАУЗЕРЕ

В **новом окне на компьютере** выполни команду туннеля из карточки нужной панели. Ниже пример для m-ui. Твоя команда может содержать другой порт или опцию ключа.

```powershell
ssh -p 22 -o ExitOnForwardFailure=yes -N -L 2054:127.0.0.1:2054 ops@203.0.113.10
```

Окно туннеля может молчать после подключения. Оставь его открытым. В браузере на компьютере открой адрес из карточки, например `http://127.0.0.1:2054/8b12b7c1c3db887a/`. Введи **логин и пароль панели**.

Для Mieru или Sudoku в m-ui открой **Inbounds** и создай вход нужного типа. Задай свободный клиентский порт и при необходимости разреши его в панели хостинга. Клиентские данные бери в m-ui.

> [!TIP]
> Для обычного входа на сервер используй пароль Linux или ключ. В браузере вводи отдельный пароль панели.

## 05 Если что-то пошло не так

| Что видишь | Что сделать |
|---|---|
| Windows не находит `ssh` или `scp` | Установи **Клиент OpenSSH** в «Дополнительных компонентах» Windows и открой PowerShell заново. |
| SSH не подключается | Проверь IP, порт, исходный логин и состояние VPS в кабинете хостинга. Если SSH недоступен, воспользуйся консолью VPS у хостинга. |
| `Permission denied` | Проверь, под какой учёткой входишь. Для исходного входа нужны данные хостинга, для новой учётки - выбранный в мастере пароль или ключ. |
| Браузер не открывает панель | Проверь, что окно SSH-туннеля открыто, и скопируй полный URL из финальной карточки, включая путь после порта. |
| Мастер показал ошибку | Запомни название этапа и посмотри последние строки журнала на сервере. |

### НА СЕРВЕРЕ

```bash
sudo tail -n 50 /var/log/debian-start.log
```

Под `root` выполни эту команду без `sudo`. Если обращаешься за помощью, отправь название этапа и текст ошибки. Проверь, что в присланном фрагменте нет паролей и ключей.

После устранения ошибки снова запусти мастер из папки с `bootstrap.sh`. Для уже созданных панелей он использует их сохранённые каталоги данных.
